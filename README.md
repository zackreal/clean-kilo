# CleanKilo CRM 🧺✨

**Sistem Manajemen Hubungan Pelanggan (CRM) Berbasis Web untuk Bisnis Laundry Modern.**
Dibangun sebagai Proyek Ujian Akhir Semester (UAS) Sistem Informasi.

## 🎯 Visi Proyek
CleanKilo dirancang untuk memodernisasi cara bisnis laundry berinteraksi dengan pelanggannya. Alih-alih menggunakan pencatatan manual, CleanKilo menyediakan ekosistem terpadu (*Admin Dashboard* & *Customer Portal*) yang mengedepankan **retensi pelanggan, gamifikasi poin, dan analisis data cerdas (Churn Management)**.

## 🚀 Fitur Utama (Core Features)

### 👨‍💼 1. Admin & Executive Dashboard (B2B)
- **Executive Overview:** Pantauan metrik bisnis (*revenue*, order masuk, rating kepuasan) secara *real-time* dengan grafik interaktif.
- **Customer Directory:** Manajemen database pelanggan dengan filter segmentasi cerdas.
- **Loyalty & Retention Program:** Sistem Tier (Silver, Gold, Platinum) otomatis berdasarkan total pengeluaran pelanggan.
- **Churn Management System (Unggulan!):** Deteksi dini pelanggan yang mulai menghilang (Ghost/Cooling Down) dan fitur *Blast Promo via WhatsApp* untuk menarik mereka kembali (Win-Back Campaign).
- **Feedback & Sentiment Analysis:** Membaca ulasan pelanggan dengan *tag* otomatis (Positif/Negatif/Netral) untuk bahan evaluasi.

### 👤 2. Customer Portal (B2C)
- **Premium User Interface:** Desain antarmuka berkelas ala Start-Up dengan animasi mulus (*Framer Motion*).
- **Live Order Tracking:** Pelanggan dapat melacak status cucian mereka secara transparan (Diterima ➔ Dicuci ➔ Selesai).
- **Gamifikasi Poin & Voucher:** Pelanggan mendapatkan koin setiap bertransaksi yang bisa ditukar menjadi Voucher Diskon.
- **Digital Invoice:** Riwayat transaksi lengkap dengan nota digital yang bisa dilihat kapan saja.
- **Interactive Feedback System:** Pelanggan bisa memberikan bintang dan memilih *smart tags* pelayanan.

## 🛠️ Tech Stack & Architecture
Proyek ini dibangun menggunakan teknologi *Front-End* paling mutakhir:
- **Framework:** Next.js 14/15 (App Router)
- **UI Library:** React.js
- **Styling:** Tailwind CSS (dengan arsitektur utilitas `clean-card`)
- **Animation Engine:** Framer Motion (`motion/react`)
- **Iconography:** Phosphor Icons
- **Deployment:** Vercel / GitHub Pages
